What this is

A rebuild of an existing Next.js whiteboard on .NET 10, built to the estate's architecture standards. Accounts are handled by authservice, the only identity provider. The web app is a Blazor Web App that acts as a backend for the browser, so tokens stay on the server. Boards and canvas state live in two services, each with its own PostgreSQL database.

It is not an AI tool. AI agents, chat, simulations, metrics and templates are out of scope (ADR 0004).

Status

Runs locally, not deployed. There is no live demo. Fly.io deployment is disabled by owner decision (ADR 0026); its workflows allow manual dispatch only.

Local development uses the Aspire AppHost, which starts PostgreSQL, authservice, the services and the web app. It needs Docker and a development signing key. The AppHost is not run in CI.

Run it locally

Install the git hooks once, then start the estate. The README has the signing-key and sign-in steps.

scripts/install-hooks.sh
scripts/run-local-stack.sh

To build and run the tests:

dotnet restore MiroClone.sln
dotnet build MiroClone.sln
dotnet test --solution MiroClone.sln
